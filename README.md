# Batima - Pesquisa de Filmes


## Descrição

**Batima** é uma aplicação web responsiva que permite aos usuários pesquisar e explorar informações sobre filmes. Com uma interface intuitiva e moderna, o projeto utiliza HTML, CSS e JavaScript para proporcionar uma experiência de usuário agradável e interativa.

## Funcionalidades

- **Pesquisa de Filmes**: Encontre informações sobre seus filmes favoritos.
- **Interface Responsiva**: A aplicação se adapta a diferentes tamanhos de tela, garantindo uma ótima experiência em dispositivos móveis e desktops.
- **Design Atraente**: Utiliza CSS para um layout moderno e estilizado.

## Tecnologias Utilizadas

- **HTML**: Estrutura básica da aplicação.
- **CSS**: Estilização e layout responsivo.
- **JavaScript**: Interatividade e manipulação de dados.

## Demonstração

Acesse a aplicação ao vivo em: [Batima - Pesquisa de Filmes](https://gui-2903.github.io/Batman4.0-responsivo-/)

## Como Usar

1. Acesse o link da aplicação.
2. Utilize a barra de pesquisa para encontrar filmes.
3. Navegue pelas informações apresentadas.
